# 🚄 车票最优助手（kunle）

> 实时查询中国铁路 12306，自动计算**最划算的买法**和**最省时的走法**，支持中转组合、性价比排序。

一个纯前端 + 轻量代理的小工具：不装 App、不登录、不广告，打开网页填「从哪到哪、哪天走」，它直接把方案算给你。

---

## 它解决什么问题

买火车票时常见的两个纠结：

1. **怎么买最划算？** 直达票往往不是最便宜的。比如北京→上海，直达二等座 553 元，但「北京→南京 + 南京→上海」两程合计可能更便宜还更早到；反过来也可能直达更划算。人肉比价几乎不可能。
2. **怎么走最省时？** 车次表只给单趟历时，不告诉你换乘要等多久、总耗时多少。

本工具把「直达车次 + 一次中转组合」全部拉出来，按**价格**和**总耗时（含换乘等待）**两个维度排序，并给出：

- 🏷️ **最划算**：所有方案里花钱最少的
- ⚡ **最省时**：含换乘等待后总耗时最短的
- ⭐ **综合最优**：按你可调的「省钱 ↔ 省时」权重加权得出
- 📈 **性价比前沿（Pareto）**：不存在任何一个方案在「更便宜」和「更快」上同时超越它

## 功能一览

| 功能 | 说明 |
|---|---|
| 实时数据 | 直连 12306 公开查询接口，车次、时刻、余票、票价都是实时的 |
| 城市级查询 | 输入「北京」即覆盖北京南/北京西/北京丰台等全部车站 |
| 拼音联想 | 支持 `bj`、`beijing`、`北京` 三种输入 |
| 直达 + 中转 | 自动尝试郑州、南京、济南、徐州、武汉等 22 个枢纽城市做一次换乘 |
| 换乘可行性 | 同站换乘至少留 30 分钟，跨站换乘留 60 分钟，等待超过 8 小时的方案直接淘汰 |
| 余票展示 | 二等座/一等座/商务座/硬卧/硬座等逐项显示「有 / 无 / 具体张数」 |
| 权重调节 | 一个滑块在「省钱」与「省时」之间滑动，推荐结果实时重算 |
| 筛选排序 | 综合最优 / 最便宜 / 最省时 / 最早出发，可只看有票、只看直达 |
| 链接分享 | 支持 `?from=北京&to=上海&date=2026-10-24` 直接带参数打开并自动查询 |
| 深色模式 | 跟随系统自动切换 |

## 技术架构（重要）

```
浏览器（静态页面 index.html + assets/）
        │  fetch /api/search
        ▼
代理层（server/server.mjs 或 worker/worker.js）
        │  https://kyfw.12306.cn/...
        ▼
12306 公开查询接口
```

**为什么必须有代理？** 12306 的接口不返回 `Access-Control-Allow-Origin` 头，浏览器出于同源策略会直接拦截跨域响应。所以静态页面无法直连，必须由服务端转发。纯 GitHub Pages 只能托管静态文件，因此线上使用时需要一个免费的 Cloudflare Worker 当代理。

用到的 12306 接口：

| 接口 | 用途 |
|---|---|
| `/otn/resources/js/framework/station_name.js` | 全国车站表（含电报码、拼音、所属城市） |
| `/otn/leftTicket/queryG` | 车次、时刻、历时、余票（`query / queryZ / queryG` 会变，代码里做了自动切换） |
| `/otn/leftTicket/queryTicketPrice` | 各席别票价 |

> 12306 查询接口需要先访问 `/otn/leftTicket/init` 拿 Cookie，且端点名会被动态下发（返回 `{"c_url":"leftTicket/queryG"}`），代码中已处理这两种情况。

## 快速开始

### 方式一：本机直接跑（推荐，最稳）

需要 Node.js 18+。

```bash
git clone https://github.com/Kunle78778/kunle.git
cd kunle
node server/server.mjs
```

然后打开 <http://127.0.0.1:8787>，直接就能查（本机代理直连 12306，无需任何账号）。

首次查询会拉取车站表，稍等一两秒。

### 方式二：部署到 GitHub Pages + Cloudflare Worker

静态页面放 GitHub Pages（免费），代理用 Cloudflare Worker（免费额度每天 10 万次请求，个人用绰绰有余）：

```bash
# 1. 部署代理（需要免费的 Cloudflare 账号，首次会引导浏览器登录）
cd worker
npx wrangler deploy
# 输出类似：https://kunle-ticket-proxy.your-name.workers.dev
```

然后打开 Pages 站点，点右上角「⚙ 设置」，把上面的 `workers.dev` 地址填进「代理地址」，保存即可。

站点地址：<https://kunle78778.github.io/kunle/>

> ⚠️ 部分云服务商的出口 IP 可能被 12306 限流或拒绝。若线上查询持续失败，请改用「方式一」在本机运行。

## 已知限制

1. **票价以 12306 当前公布为准**：不含任何手续费；中转方案需你分两段自行购票，存在第二程售罄风险。
2. **只算一次中转**：两次及以上换乘组合数爆炸，暂不支持。
3. **枢纽是精选列表**：默认尝试 22 个主要枢纽中的前 8 个，小站之间的换乘可能覆盖不到。
4. **预售期约 15 天**：页面日期选择器已做限制。
5. **接口可能变更**：12306 会调整接口路径与参数，代码已做端点自动跟随，若结构大改仍需更新解析。
6. **代理限制**：云厂商出口 IP 有被限流风险，见上文说明。
